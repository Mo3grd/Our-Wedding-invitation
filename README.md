# دعوة محمد وميرنا — Vercel

النسخة النهائية تشمل:
- شاشة الظرف الافتتاحية.
- فيديو فتح الأبواب عند الضغط.
- تشغيل الموسيقى مع الضغط.
- صورة محمد وميرنا على الـVespa في الـHero.
- خط عربي مهيأ لاستخدام Thmanyah إذا كان مثبتًا، مع fallback عربي ويب.
- حذف قسم «بعض من لحظاتنا» بالكامل.
- أيقونات التاريخ والساعة والموقع المرفوعة من المستخدم.
- فريم Floral متجاوب مع Parallax خفيف أثناء الـscroll.
- خريطة Google Maps ظاهرة تلقائيًا بجانب بوكس المكان على الشاشات الكبيرة، وأسفل البوكس على الموبايل.
- عد تنازلي حتى 7 أكتوبر 2026 الساعة 7:00 مساءً بتوقيت السعودية.

## مهم بخصوص خط ثمانية
ترخيص خط ثمانية يسمح باستخدامه في مواقع الويب، لكنه يمنع استضافة ملف الخط نفسه على موقعك. لذلك لم نضع ملف OTF داخل المشروع. الكود يطلب اسم الخط أولًا (`Thmanyah`) ليستفيد منه إذا كان مثبتًا على جهاز المستخدم، ثم يستخدم خط ويب بديلًا على الأجهزة التي لا تملكه.

## رفع المشروع على GitHub ثم Vercel
1. فك ضغط الملف.
2. افتح GitHub وأنشئ Repository جديد، مثل `Our-Wedding-invitation`.
3. افتح مجلد `wedding-invite`.
4. ارفع **كل الملفات والمجلدات الموجودة داخله** إلى جذر الـRepository.
5. تأكد أن شكل المستودع يكون:
   - `index.html`
   - `style.css`
   - `script.js`
   - `assets/`
6. داخل `assets/` يجب أن تجد: الصور + `opening.mp4` + `wedding-song.mp3` + `floral-frame.svg`.
7. افتح Vercel وسجل الدخول باستخدام GitHub.
8. اختر Add New → Project.
9. اختر Repository الدعوة.
10. Framework Preset: Other.
11. Build Command: اتركه فارغًا.
12. Output Directory: اتركه فارغًا.
13. Install Command: اتركه افتراضيًا.
14. اضغط Deploy.
